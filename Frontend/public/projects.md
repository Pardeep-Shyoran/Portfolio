# Selected Works — Pardeep Shyoran

A curated catalog of 7 full-stack platforms, real-time collaboration engines, and frontend experiments.

## KodraX — Real-Time Collaborative Code Editor & Execution Engine

- **Category**: Collaborative Web Application
- **Role**: Full-Stack Developer
- **Featured**: Yes
- **Technologies**: React, Node.js, Express, MongoDB, Socket.IO, Judge0 CE, Monaco Editor, JWT
- **Case Study**: https://pardeep-shyoran.me/projects/kodrax
- **Markdown**: https://pardeep-shyoran.me/projects/kodrax.md
- **Live Demo**: https://kodraxlive.vercel.app/
- **Repository**: https://github.com/Pardeep-Shyoran/KodraX

KodraX is a collaborative development environment that allows developers to create or join private rooms, write and edit code together in real time via Socket.IO, switch between multiple programming languages, and execute programs through Judge0 CE with synchronized output broadcast.

## Rivo — Scalable Music Streaming & Artist Management Platform

- **Category**: Distributed Audio Platform
- **Role**: Full-Stack Developer
- **Featured**: Yes
- **Technologies**: React, Node.js, Express, MongoDB, RabbitMQ, AWS S3, ImageKit, JWT
- **Case Study**: https://pardeep-shyoran.me/projects/rivo
- **Markdown**: https://pardeep-shyoran.me/projects/rivo.md
- **Live Demo**: https://rivo-music.vercel.app/
- **Repository**: https://github.com/Pardeep-Shyoran/Rivo

Rivo is a full-stack audio streaming platform engineered with decoupled microservices. It delivers role-based experiences for artists and listeners, secure audio uploads via AWS S3, asynchronous email notifications using RabbitMQ message queues, and playback history tracking.

## MoodSwinger — Facial Expression Detection & Emotion-Based Audio Player

- **Category**: Computer Vision & Audio Experiment
- **Role**: Full-Stack Developer
- **Featured**: No
- **Technologies**: React, Node.js, Express, MongoDB, face-api.js, WebRTC
- **Case Study**: https://pardeep-shyoran.me/projects/moodswinger
- **Markdown**: https://pardeep-shyoran.me/projects/moodswinger.md
- **Live Demo**: https://moodswinger.vercel.app
- **Repository**: https://github.com/Pardeep-Shyoran/Moody-Player

MoodSwinger is an experimental web application that pairs computer vision with audio streaming. By analyzing facial landmarks via webcam in the browser, the application classifies emotional states—such as happy, neutral, or angry—and automatically queues corresponding playlists.

## Windows 11 Web Clone — Framework-Free Browser OS Desktop Simulation

- **Category**: Frontend Engineering Simulation
- **Role**: Frontend Developer
- **Featured**: No
- **Technologies**: HTML5, CSS3, Vanilla JavaScript, DOM Manipulation, Event Architecture
- **Case Study**: https://pardeep-shyoran.me/projects/windows-11
- **Markdown**: https://pardeep-shyoran.me/projects/windows-11.md
- **Live Demo**: https://os-windows-11.vercel.app/
- **Repository**: https://github.com/Pardeep-Shyoran/Windows-11

An architectural exploration of the Windows 11 operating system interface built entirely in the browser using vanilla web standards. It replicates desktop window management, an interactive taskbar, start menu, functional Notepad, file explorer simulation, and theme toggling without any external libraries.
